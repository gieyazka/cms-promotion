# Flutter Integration Guide for CMS Promotion

This guide explains how to render the promotion content generated by Tiptap in your Flutter application.

## 1. Data Structure
The promotions are stored as JSON in the Tiptap/ProseMirror format. Each promotion has:
- `id`: String
- `title`: String
- `content`: JSON (ProseMirror tree)
- `createdAt`: ISO Date string
- `status`: "draft" | "active"

### Example Content JSON
```json
{
  "type": "doc",
  "content": [
    {
      "type": "heading",
      "attrs": { "level": 1 },
      "content": [ { "type": "text", "text": "Promotion Title" } ]
    },
    {
      "type": "paragraph",
      "content": [
        { "type": "text", "text": "This is a " },
        { "type": "text", "marks": [ { "type": "bold" } ], "text": "bold" },
        { "type": "text", "text": " text." }
      ]
    },
    {
      "type": "image",
      "attrs": { "src": "https://res.cloudinary.com/..." }
    }
  ]
}
```

## 2. Rendering in Flutter

### Option A: Use a Library
You can use packages like `flutter_html` if you convert JSON to HTML on the server, or find a ProseMirror renderer for Flutter.

### Option B: Custom Renderer (Recommended for Native look)
Create a recursive function to map JSON nodes to Flutter Widgets.

```dart
Widget renderNode(Map<String, dynamic> node) {
  switch (node['type']) {
    case 'doc':
      return Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: (node['content'] as List).map((n) => renderNode(n)).toList(),
      );
    case 'heading':
      int level = node['attrs']['level'];
      return Padding(
        padding: EdgeInsets.symmetric(vertical: 8.0),
        child: Text(
          node['content'][0]['text'],
          style: TextStyle(
            fontSize: level == 1 ? 24 : 20,
            fontWeight: FontWeight.bold,
          ),
        ),
      );
    case 'paragraph':
      return Padding(
        padding: EdgeInsets.symmetric(vertical: 4.0),
        child: RichText(
          text: TextSpan(
            style: TextStyle(color: Colors.black, fontSize: 16),
            children: (node['content'] as List).map((n) => renderTextNode(n)).toList(),
          ),
        ),
      );
    case 'image':
      return Image.network(node['attrs']['src']);
    default:
      return SizedBox.shrink();
  }
}

TextSpan renderTextNode(Map<String, dynamic> node) {
  bool isBold = false;
  if (node['marks'] != null) {
    isBold = (node['marks'] as List).any((m) => m['type'] == 'bold');
  }
  return TextSpan(
    text: node['text'],
    style: TextStyle(
      fontWeight: isBold ? FontWeight.bold : FontWeight.normal,
    ),
  );
}
```

## 3. API Connection
Fetch the promotion list or detail from your Next.js API:
- List: `GET /api/promotions`
- Detail: `GET /api/promotions/[id]`
